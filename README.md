# DataSphere – Multi-Domain Data Analytics Platform

A beginner-friendly data analytics and business intelligence platform built using Python and Streamlit.

## Overview

DataSphere helps users explore datasets, understand data quality, perform exploratory data analysis, and discover useful insights through interactive visualizations.

The platform is designed to support datasets from multiple domains, including business, education, e-commerce, and finance.

## Features

- CSV dataset upload
- Dataset preview and overview
- Missing value analysis
- Duplicate record detection
- Statistical summary
- Unique value analysis
- Interactive data visualizations
- Correlation heatmap
- Business intelligence analysis
- Multi-domain dynamic analytics
- Downloadable analysis reports

## Technology Stack

- Python
- Pandas
- NumPy
- Streamlit

## Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/rutvikdalvi39-collab/DataSphere.git
```

### 2. Navigate to the project folder

```bash
cd DataSphere
```

### 3. Create a virtual environment

```bash
py -m venv .venv
```

### 4. Install dependencies

```bash
.venv\Scripts\python.exe -m pip install streamlit pandas numpy plotly
```

### 5. Run the application

```bash
.venv\Scripts\python.exe -m streamlit run app.py
```

The application will open in your browser.
